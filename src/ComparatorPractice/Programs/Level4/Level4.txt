🔴 19️⃣ Sort Version Numbers Correctly
🔍 Problem Understanding

Lexicographic sorting fails:

1.2.10 ❌ < 1.2.2

🔹 Correct Approach

Split version string

Compare numeric parts one by one

🔹 Comparator Code
versions.sort((v1, v2) -> {
    String[] a1 = v1.split("\\.");
    String[] a2 = v2.split("\\.");

    int max = Math.max(a1.length, a2.length);

    for (int i = 0; i < max; i++) {
        int n1 = i < a1.length ? Integer.parseInt(a1[i]) : 0;
        int n2 = i < a2.length ? Integer.parseInt(a2[i]) : 0;

        if (n1 != n2) {
            return Integer.compare(n1, n2);
        }
    }
    return 0;
});

🎤 Interview Explanation

“Each version segment is compared numerically instead of as a string to ensure correct ordering.”

🔴 20️⃣ Top 3 Highest Paid Employees (Streams + Comparator)
🔍 Problem Understanding

Sort descending by salary

Return top 3

🔹 Solution
List<Employee> top3 =
    employees.stream()
             .sorted(Comparator.comparing(Employee::getSalary).reversed())
             .limit(3)
             .toList();

🧠 Alternative (More Efficient for Large Lists)
List<Employee> top3 =
    employees.stream()
             .collect(Collectors.collectingAndThen(
                 Collectors.toList(),
                 list -> list.stream()
                             .sorted(Comparator.comparing(Employee::getSalary).reversed())
                             .limit(3)
                             .toList()
             ));

🎤 Interview Explanation

“Streams allow clean transformation pipelines, and comparator reversal ensures descending order.”
